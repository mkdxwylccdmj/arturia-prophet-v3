## Overview

Prophet V3 combines V-Collection models of the Prophet-5 analog polysynth and Prophet-VS vector synthesizer in a single plugin, offering both vintage pads and the complex vector-crossfade morphing of the VS.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Prophet V3** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Prophet-5 Model** | Five-voice analog emulation of the classic Curtis chip architecture |
| **Prophet-VS Model** | Vector synthesis with 4-oscillator XY joystick crossfading |
| **Vector Sequencer** | Animate vector position over time with the VS step sequencer |
| **Hybrid Mode** | Route Prophet-5 voices through VS vector crossfade architecture |
